1. 按 `firmware/README.md` 接线（OLED VCC→3V3、GND、SCL→14、SDA→15）
2. FTDI 接好：`5V / GND / U0R→TX / U0T→RX / IO0→GND`
3. 烧录：

```powershell
powershell -ExecutionPolicy Bypass -File D:\CS\esp32display\firmware\tools\build.ps1 -Upload COM3
```
（`COM3` 换成设备管理器里的实际端口）

4. 拔掉 `IO0-GND`，按 RST，看屏幕：
   - **全屏点亮 0.8s** → 顶部约 16 行是不是黄色？（决定 v6 配色成立与否）

   - 边框 + `TOP 16 ROWS / should be YELLOW` 文字

5. 记录：I2C 地址、面板类型、红灯是否每秒闪

## 9. 已知风险 / 注意事项

1. **v6 布局已定稿**，改布局要连带更新 `docs/images/v6` 与 05。
2. `tools/build.ps1` 必须存成 **UTF-8 with BOM**（PowerShell 5.1 读中文会乱码），
   它生成的 `.ino` 必须 **UTF-8 无 BOM**（否则 arduino-cli 报 `'﻿' does not name a type`）。
3. `PartitionScheme=default`（1.2MB APP ×2）才是带 OTA 的分区；默认的 `huge_app` 不能 OTA。
4. PlatformIO 的 `platformio.ini` 保留着，等 CDN 恢复或换网络可直接用。
5. `firmware/.build/`、`.pio/` 都是构建产物，已在 `.gitignore` 里。
