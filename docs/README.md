# ESP32-CAM 桌面时钟

> 固件版本 **1.0.0-esp32cam** ｜ 作者 **shane** ｜ 完成日期 2026-11-02

把吃灰的 **ESP32-CAM（AI-Thinker）拔掉摄像头当普通 ESP32 用**，外接一块 **128×64 SSD1315 OLED（I2C 四针）**，做成一台北苏风格的桌面时钟：**黄区大字时间 + 蓝区日期/农历/天气/状态**。

```
        18:07:14            ← 黄色（面板上 0–15 行是黄色区）
      11-02 周一 九月廿四
   ─ ─ ─ ─ ─ ─ ─ ─
    ☀   16.3      H 20   L 13
                  68%     N1
WiFi OK                  18:07
```

---

## 1. 功能一览

| 功能 | 说明 |
|---|---|
| **时钟** | SNTP 校时（阿里云/腾讯/国际池），时区 `CST-8`，每 12 小时自动重校 |
| **日期** | `11-02 周一 九月廿四` —— 公历 + 星期 + 农历（1900–2100，支持闰月） |
| **天气** | Open-Meteo（苏州），30 分钟刷新，失败按 1→5→30 分钟退避 |
| **天气内容** | 图标（12 种）+ 当前温度（一位小数）+ 今日最高/最低 + 相对湿度 + 风向风级 |
| **离线态** | 数据超 2 小时未更新 → 更新时间前加 `!`；断网保留旧数据 |
| **配网** | 没配网自动开热点 `ESP32-Clock`，手机打开 `192.168.4.1` 即可配网，无需改代码 |
| **升级** | 三种方式：串口 / ArduinoOTA / **浏览器上传 .bin** |
| **自愈** | 看门狗式重启（堆过低 5 分钟、WiFi 断 30 分钟） |
| **调试** | 设备自带 HTTP API：状态、天气、图标预览、配网切换 |

## 2. 硬件

| 部件 | 规格 | 说明 |
|---|---|---|
| 主控 | ESP32-CAM（AI-Thinker） | 4MB Flash + 4MB PSRAM，**无 USB**，摄像头已拆 |
| 屏幕 | OLED 128×64 SSD1315（I2C 四针） | **黄蓝双色**：0–15 行黄、16–63 行蓝 |
| 烧录 | CH340 底板 / FTDI | 首次与救砖用；之后走 OTA |
| 电源 | 5V / 2A + 100µF | 不要用 3V3 给板子供电 |

**接线（关键）**：I2C 只能挂 `SDA=GPIO15` / `SCL=GPIO14`（ESP32-CAM 10 个可用 GPIO 里唯一不踩启动 strapping 的组合，代价是不能再用 SD 卡）。

详见 [08-接线与刷机教程](08-接线与刷机教程.md)。

## 3. 快速上手

```bat
:: 1) 改 WiFi（2.4GHz）。也可以不改：留空则开机自动进配网模式
notepad firmware\include\config.h

:: 2) 编译
cd firmware
tools\build.cmd

:: 3) 烧录（三选一）
tools\build.cmd -Upload COM5              :: 串口（需 IO0 接地）
tools\build.cmd -Upload 192.168.1.23      :: OTA（需同网）
:: 或浏览器打开 http://<设备IP>/update 上传 .bin
```

> `build.cmd` 是 cmd 包装器，内部带 `-ExecutionPolicy Bypass`，避免"禁止运行脚本"报错。

## 4. HTTP 接口

设备联网后自带 Web 服务，完整说明见 **[10-HTTP接口](10-HTTP接口.md)**。

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/` | 状态页（HTML） |
| GET | `/status` | 状态 JSON（含版本、作者、农历、天气全字段、运行统计） |
| GET | `/update` | 固件升级页 |
| POST | `/update` | 上传 `.bin` 并重启 |
| GET | `/reboot` | 重启 |
| GET | `/debug/wx` | 立刻重拉天气 |
| GET | `/debug/icon?n=0..11` | 放大预览某个天气图标 15 秒 |
| GET | `/debug/portal` | 切到配网模式 |

```bash
curl http://192.168.124.24/status
# {"fw":"1.0.0-esp32cam","author":"shane","lunar":"九月廿四", ...}
```

├── src/
│   ├── main.cpp          启动流程 / 主循环 / OTA / 看门狗

│   ├── net_weather.cpp   Open-Meteo + 映射 + 退避
