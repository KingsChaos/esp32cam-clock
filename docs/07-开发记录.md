## 3. 踩坑与解决

| 现象 | 原因 | 解决 |
|---|---|---|
| `'pio' 不是内部或外部命令` | PlatformIO 只装在临时 venv，没进 PATH | 装到 `~/.pio-venv` 并写入用户 PATH（新终端生效） |
| `pio run` 卡 `Downloading 0%` | PlatformIO 包 CDN 在本机不可达（TCP 通但无数据） | 放弃 PIO 首次构建，改 arduino-cli |
| `arduino-cli core install` 报 `context deadline exceeded` / `server failed to respond` | 直连 GitHub 大包会断流 | 用 `curl -C -` 分段并行下载（6 并发）+ SHA256 校验，再放进 `Arduino15/staging/packages` |
| `'﻿' does not name a type` | 生成的 `.ino` 带 UTF-8 BOM | `.ino` 用 UTF-8 **无 BOM** 写；`.ps1` 反而要 **带 BOM**（否则 PowerShell 5.1 中文乱码） |
| `Can't open sketch: main file missing` | sketch 目录名与 `.ino` 不同名 | 目录 `esp32clock/` + 文件 `esp32clock.ino` |
| `$active += ...` 报 `op_Addition` | PowerShell 单元素时变量退化为 PSObject | 用 `@(...)` 强制数组 |
| 7 段数码"不好看" | 2px 笔画 + 10px 宽在 0.96" 上偏硬 | v6 撤回，回归 16px 文字字体 |
