### 恢复方法

```bat
:: 1) 解压后修改 WiFi（2.4GHz）
notepad firmware\include\config.h

:: 2) 编译
cd firmware
tools\build.cmd

:: 3) 烧录（二选一）
tools\build.cmd -Upload COM5              :: 串口，需要 IO0 接地
tools\build.cmd -Upload <设备IP>          :: OTA，设备必须已联网
```
